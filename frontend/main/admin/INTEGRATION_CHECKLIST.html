❓ 常见问题

Q: 如何验证权限校验是否生效？

A: 用一个低级别管理员账户尝试执行高级别操作，应该得到 403 Forbidden 响应。

Q: 如何支持一人多职？

A: 已支持。通过 admin_positions 表的一对多关系，和 X-Active-Position-Id header 激活不同职位。

Q: 节点选择器为什么是占位符？

A: 待后端完成真实数据库集成后，可根据实际的学校/商户/档口树结构实现。当前已预留接口。

Q: 搜索支持大数据量吗？

A: 当前为客户端前缀匹配（适合 <1000 条）。超过 1000 条建议改为后端分页搜索。

⚠️ 重要提示

1. 伪代码转换

所有 db.query() 伪代码需替换为真实的数据库执行，例如使用 mysql2/promise 或 ORM（Sequelize）。

2. 安全配置

确保 JWT secret 已配置到环保变量 .env 文件，不要硬编码。

3. localStorage 依赖

前端依赖以下键：
• adminToken - JWT 认证令牌
• adminActivePositionId - 激活的职位 ID
