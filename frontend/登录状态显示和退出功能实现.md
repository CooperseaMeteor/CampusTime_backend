# 用户界面登录状态显示和退出按钮功能实现

## 概述

本次操作解决了用户界面中存在的两个问题：
1. 用户成功登录后，主界面右上角仍显示"登录"字样的错误显示问题
2. 实现右上角"退出"按钮的跳转功能

## 修改的文件列表

### 1. 新增文件

#### 1.1 navigation-manager.js
- **路径**: `main/user/navigation-manager.js`
- **功能**: 创建统一的导航栏状态管理器
- **主要代码**:
```javascript
// 导航栏管理器 - 统一处理登录状态显示和退出功能
class NavigationManager {
    constructor() {
        this.init();
    }
    
    // 初始化导航栏
    init() {
        // 页面加载时更新导航栏状态
        document.addEventListener('DOMContentLoaded', () => {
            this.updateNavigationState();
        });
    }
    
    // 更新导航栏状态
    updateNavigationState() {
        const isLoggedIn = Router.isLoggedIn();
        const loginItem = document.querySelector('.nav-item[onclick*="login"]');
        const logoutItem = document.querySelector('.nav-item:not([onclick*="login"])');
        
        if (loginItem && logoutItem) {
            if (isLoggedIn) {
                // 用户已登录，显示退出按钮
                loginItem.style.display = 'none';
                logoutItem.style.display = 'block';
                logoutItem.textContent = '退出';
                logoutItem.setAttribute('onclick', 'NavigationManager.handleLogout()');
                logoutItem.style.cursor = 'pointer';
            } else {
                // 用户未登录，显示登录按钮
                loginItem.style.display = 'block';
                logoutItem.style.display = 'none';
                loginItem.textContent = '登录';
            }
        }
    }
    
    // 处理退出登录
    static handleLogout() {
        if (confirm('确定要退出登录吗？')) {
            // 清除用户数据
            Router.logout();
            
            // 更新导航栏状态
            const navManager = new NavigationManager();
            navManager.updateNavigationState();
        }
    }
}

// 创建全局导航管理器实例
const navManager = new NavigationManager();
```

## 实现的功能

### 1. 登录状态显示修复

#### 1.1 实现登录状态检测机制
- 使用 `Router.isLoggedIn()` 检测用户登录状态
- 根据登录状态显示/隐藏相应的导航栏按钮
- 确保状态切换在所有页面刷新和导航场景下保持一致性

#### 1.2 状态切换逻辑
- 用户已登录：隐藏"登录"按钮，显示"退出"按钮
- 用户未登录：显示"登录"按钮，隐藏"退出"按钮
- 动态设置按钮文本和点击事件

### 2. 退出按钮功能实现

#### 2.1 退出功能
- 清除用户登录状态、会话信息或令牌
- 使用 `Router.logout()` 方法处理退出逻辑
- 配置退出后的跳转路径，重定向到登录页

#### 2.2 用户体验优化
- 添加确认提示，防止用户误操作
- 退出后自动更新导航栏状态
- 确保操作过程中的用户体验流畅

### 3. 统一导航栏管理

#### 3.1 组件化设计
- 创建可复用的导航栏管理组件
- 避免在每个页面重复实现相同功能
- 提供统一的接口和方法

#### 3.2 自动初始化
- 页面加载时自动更新导航栏状态
- 监听DOM加载完成事件
- 确保状态实时同步

## 使用指南

### 1. 引入导航管理器
在需要登录状态管理的页面中添加以下代码：
```html
<script src="/main/user/navigation-manager.js"></script>
```

### 2. 设置导航栏HTML
确保导航栏包含以下元素：
```html
<div class="nav-item" onclick="ensureLoginModal(openLoginModal)">登录</div>
<div class="nav-item" onclick="NavigationManager.handleLogout()">退出</div>
```

### 3. 自定义状态更新
如需手动更新导航栏状态，可调用：
```javascript
const navManager = new NavigationManager();
navManager.updateNavigationState();
```

## 注意事项

1. 确保页面已引入Router类和config.js
2. 导航栏元素的类名和结构需保持一致
3. 退出操作会清除所有用户数据，请谨慎使用
4. 状态更新是自动的，一般情况下无需手动干预
